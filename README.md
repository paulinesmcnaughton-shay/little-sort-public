# Little Sort

A cozy sorting puzzle game for iOS and Android. Designed, built and shipped solo by Pauline Shay under Celestial Works LLC.

**[Download on the App Store](https://apps.apple.com/app/id6794051571)**

## What it is

Three game modes in one app:

- **Sort** — tap or drag items between shelves until every shelf holds one kind.
- **Tubes** — pour colored layers until each tube is a single color.
- **Match It** — a timed match-three mode with power-ups and blockers.

Plus daily rewards, login streaks, hint stars, themes, sound and haptics.

## My role

End to end: product design, visual design, game design and engineering.

- Designed the full UI, item art direction, themes and motion.
- Built the app in React Native with a typed, tested game engine.
- Shipped to the App Store and Google Play, including in-app purchases, subscriptions, ads, sign-in and cloud save.

## Tech stack

- Expo / React Native, TypeScript (strict)
- Supabase (auth, cloud save, edge functions)
- RevenueCat (subscriptions and in-app purchases)
- Google AdMob
- EAS Build and Submit

## What's in this repo

A showcase of the front end and game engine:

- `src/screens`, `src/components`: every screen and UI component
- `src/game`: the Sort, Tubes and Match It game rules
- `src/theme`: design tokens and themes
- `tests`: unit tests for the game engine

Left out on purpose: the backend, purchases, ads, cloud save, level data and app configuration. This copy won't run as a full app.
